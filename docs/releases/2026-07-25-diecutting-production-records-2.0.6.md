# Edge Host / AP / CP 2.0.6

本版本以前向补丁恢复正、负极模切生产数据语义，不覆盖 2.0.5，也不改变 Cloud 或 AICopilot。

## 修复内容

- 生产数据只在 Host 主队列实际消费并发布 `CellCompletedEvent` 后落库；PLC 当前值、仅入队成功、运行上下文和上传结果不再生成生产行。
- AP、CP 使用相互独立的 SQLite 过站记录库，支持幂等写入、当前生产日、单设备/全部设备筛选和最近 500 条查询。
- “生产数据”页只显示设备编码、设备名称、MG 槽位、弹夹码、开始/完成时间、过站数量、速度和队列处理时间。
- 今日总览从同一过站记录库聚合产量，不再从 PLC 当前快照推算。
- MG1、MG2 改为两个可独立运行的任务，任务键、状态和完成记录按槽位隔离。
- AP/CP 模块配置及首装 activation machine profile 默认关闭 PLC 设备播种；打包时发现默认播种开启将直接失败。
- MES 开启但服务地址、出站路径、签名、上位机编码或工序编码缺失时，在发起 HTTP 请求前明确阻断。
- SDK 升至 2.0.3，新增只读设备选择上下文和模块生产记录持久化/汇总契约；Host 保留唯一可写设备选择服务。

## 数据与兼容

- Host、AP、CP 产品版本统一为 `2.0.6`；插件 Host API 代际仍为 `2.0.0`，插件兼容窗口精确锁定 Host `2.0.6`。
- MES/Cloud 上传失败不会删除已执行的本地过站记录，只更新各自同步诊断。
- 没有 `CellCompletedEvent` 时生产页显示明确空态，不填充示例数据。

## 现场验收

发布后须分别对 AP/CP 的 MG1/MG2 执行受控过站，逐项核对主队列日志、生产页单行、独立 SQLite 记录和今日产量一致。真实 PLC、MES、Cloud 现场链路未完成上述对账前，不得仅凭卡片、按钮、版本或连接状态宣告生产恢复。
