## 4. 宿主与 Cloud/MES 后续处理顺序

1. 后续批次开始前固定授权仓库基线；Cloud、SDK、Private Plugins 未获写入授权时只读。
2. 逐条处理 `GAP-HL-*`、`GAP-CM-*`；完成项必须取得源码和受影响测试证据，禁止仅凭工作区修改状态判定已解决。
