## 7. PLC 后续统一处理顺序

1. 等其它窗口结束后，重新固定 Host、SDK、Private Plugins、正式规则和本临时目录的最终字节。
2. 逐条重审 `GAP-PLC-001` 至 `GAP-PLC-012`；当前某个文件出现修改状态不得直接解释为问题已解决。
3. 先统一 `PlcCode` 身份、首启播种、任务绑定和唯一 PLC 请求调度，再处理 buffer 质量、批读分块及 AP/CP 三个任务。
4. 读取链整改必须保持“不同 PLC 并行、同一 PLC 单连接串行、局部任务失败隔离”，禁止用多连接或全 PLC 停机替代。
5. AP/CP 状态机验收必须覆盖本次条码失败、真实空码、连续三次空码、数量/速度过期和 MG1/MG2 隔离。
6. 全部实现与受影响测试完成后，把仍然有效的 `PLC-*` 规则迁入正式唯一规则入口；随后删除本临时目录。
