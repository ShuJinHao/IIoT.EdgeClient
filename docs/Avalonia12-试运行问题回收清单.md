# Avalonia 12 试运行问题回收清单

## 使用口径

- 本清单只记录 Avalonia 旁路迁移试运行问题，不记录 Cloud/MES 清理、重试、删除或 PLC 策略调整。
- P0 阻断生产切换，P1 阻断现场试运行继续推进，P2 可延期但必须保留证据。
- 问题关闭必须填写复验命令、证据路径和处理结论。
- P1 只能由现场证据关闭；证据不足时不得把 P1 标记为已关闭。

## 当前结论

截至第十八批开始，自动化候选门禁可验证 P0 技术项；P1 项必须通过现场证据导入、复审和预审闭环关闭。未形成已填写验收记录、关键截图、`ReadyForDefaultEntryReview` 复审结果和完整人工签字前，不允许把 Avalonia 切成生产默认入口。
