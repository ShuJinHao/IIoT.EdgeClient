# 改动复盘与规则沉淀

本文档是 `IIoT.EdgeClient` 的项目滚动复盘入口，最新记录放在最前。每次代码改动完成前必须更新本文件，并判断是否需要把长期结论沉淀到 `docs/客户端规则.md`、专题契约或工作区 `docs/总规则.md` / `docs/历史核心记录.md`。

默认只更新本滚动文档，不为每个任务新增单独流水文档。只有形成可长期复用的业务规则、技术契约、部署口径或验收口径时，才新增专题文档。

没有形成长期规则时，复盘记录必须写明固定结论“无新增长期规则”及原因。

## 2026-06-29 改动收口与 PLC 选择契约门禁

- 改动范围：工作区 `AGENTS.md`、`docs/总规则.md`、`docs/历史核心记录.md`，以及 `IIoT.EdgeClient/docs` 和 `src/Tests/IIoT.Edge.Shell.Tests/RepositoryHygieneTests.cs`。
- 改动原因：用户指出已验收的 PLC/IO/Dashboard 设备选择与状态展示链路被后续改动破坏，且之前没有强制的改后复盘和规则提炼机制。
- 影响面：仅规则、文档和仓库卫生测试；不修改 PLC、IO、Dashboard、MES、Cloud、Runtime 或业务链路代码。
- 改前阅读：已阅读工作区 `AGENTS.md`、`docs/总规则.md`、`docs/业务规则.md`、`docs/历史核心记录.md`、`IIoT.EdgeClient/docs/客户端规则.md`、Cloud/AICopilot 规则、EdgeClient 相关源码和测试；已查看 EdgeClient 近期相关 git 历史。
- 规则提炼：
  - 全局新增“改动收口强制规则”，要求每次代码改动完成前更新项目滚动复盘文档并提炼长期规则。
  - EdgeClient 新增 PLC 选择与状态展示专题契约，固化 `IDeviceSelectionService`、`IoMappingEntity`、IO 单点/连续读取和 Dashboard `PLC 状态表` 的边界。
  - EdgeClient 仓库卫生测试新增文档门禁，防止删除滚动复盘、PLC 选择契约和 UI 验收红线。
- 验证命令：
  - `rg "改动复盘|规则沉淀|IDeviceSelectionService|PLC 状态表|IoMappingEntity" AGENTS.md docs IIoT.EdgeClient/docs`
  - `dotnet test IIoT.EdgeClient/src/Tests/IIoT.Edge.Shell.Tests -p:BuildInParallel=false --disable-build-servers`
- 验证结果：`rg` 检索通过；`IIoT.Edge.Shell.Tests` 最终通过 129 个测试。新增门禁测试曾暴露复盘固定短语和 PLC 状态表固定句式缺失，已补齐后通过。
