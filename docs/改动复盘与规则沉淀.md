本文档是 `IIoT.EdgeClient` 的项目滚动复盘入口，最新记录放在最前。每次代码改动完成前必须更新本文件，并判断是否需要把长期结论沉淀到 `docs/客户端规则.md`、专题契约或工作区 `docs/总规则.md` / `docs/历史核心记录.md`。

没有形成长期规则时，复盘记录必须写明固定结论“无新增长期规则”及原因。

## 2026-07-01 现场 PLC 状态、模切采集可见性和 IO 32 位显示返修

- 改动范围：仅修改 `IIoT.EdgeClient`。覆盖 IO 页面 `Int32/UInt32/DWord` 解码显示、PLC 运行快照时间戳、Dashboard PLC 详情弹层和连接超时展示、模切默认 PLC 端口 `65531`、旧默认端口迁移、模切 MES 旧默认地址 warn、模切采集/MES 上传中文日志和限流脱敏。未修改 CloudPlatform、AICopilot、发布脚本、部署产物、Launcher mutex 根因、SaveCommand 黄色项或服务器配置。
- 改动原因：现场 IO 页面把 32 位点位显示成两个 16 位 word；PLC 页面详情在无错误时打不开，连接失败时可能长时间只显示“连接中”；用户无法从日志判断模切每轮采集、跳过、上传成功或失败原因；播种端口仍有旧 `65530`；MES 地址需要确认新默认 `http://10.98.101.247:8080`，旧默认值出现时必须可见 warn。
- 影响面：IO 页面只改变显示层和编辑值解码，不改变 PLC buffer、点位保存或模切业务采集 codec；PLC 状态存储新增最近尝试、最近读取和状态变更时间，Dashboard 仅按真实时间戳做 UI 超时展示，不伪造 PLC 断开；模切播种只迁移“设备名和默认 IP 均匹配且仍为旧默认端口 65530”的老设备，不覆盖人工改过 IP 或非默认端口；模切 MES 日志只输出 base URL、路径、采集摘要和结果，不输出 token/sign/密钥。
- 关键实现：
  - `IoViewSignalValueUpdater` 增加 `Int32/UInt32/DWord` 两 word 合成显示和 `DecodeSingleEditValue` 同步解码，字序按现场样例低字在前、高字在后，例如 `54621, 15 => 1037661`；保留现有 Float 解码。
  - `PlcConnectionRuntimeSnapshot` / `PlcConnectionStatusStore` 增加 `LastAttemptAtUtc`、`LastReadAtUtc`、`StateChangedAtUtc`，真实连接、读取、断开和运行异常都会维护时间戳。
  - Dashboard PLC 表以配置设备带出 IP、端口、型号、协议帧；详情按钮不再依赖错误文本；详情弹层改为运行详情；`Connecting` 超过展示阈值时显示“连接超时”。
  - 模切默认设备种子和硬件模板端口改为 `65531`；开发样本导入器对旧默认 `65530` 做受控迁移，并保留用户自定义端口。
  - `DieCuttingModuleDefinition` 统一持有 AP/CP 旧 MES 地址；参数注册和运行任务共用该旧值表；运行时发现旧默认地址时输出中文 warn。
  - `DieCuttingRealtimeSampleUploadTask` 增加中文配置摘要、PLC 未连接/数据不新鲜/采集上传结果/设备状态结果日志，按结果变化或固定间隔限流，失败和恢复即时可见。
- 规则提炼：形成长期规则，已写入 `docs/客户端规则.md`、`docs/PLC选择与状态展示控制.md` 和 `docs/模切MES对接口径.md`。新增规则包括：IO 页面必须按数据类型解码多 word 数值；Dashboard PLC 详情必须无错误也可打开并展示端点/协议帧/最近尝试/最近读取；模切 AP/CP 默认 PLC 端口为 `65531`，旧 `65530` 只能作为受控迁移条件；模切采集和 MES 上传必须有中文、限流、脱敏运行日志。
